## Design Specificity Verdict

**LLM assessment:** Domain copy is authored (recorte, praça, motoboy no jantar, chamar o parceiro). Composition is not. ## Overall Impression

The bones of the job are in the code: one recorte, alerts that name a person/time-band/threshold, an agent that can answer from that slice without a key. The screen does not stage that job. A recruiter can spend two minutes in GMV charts and never meet the differentiator. Biggest opportunity: make **alerta + ação** the first readable object after Recorte, and treat KPIs as evidence under it — not a six-column poster above it.

## What's Working

1. **Recorte as a stated contract.** Sidebar header “Recorte”, caption that KPIs/charts/agent use only this slice, page caption repeating it, empty recorte that *stops* the rest of the page. That is the right product principle, visible in UI copy.
2. **Alerts already speak like ops, not like toast.** “Reforçar frota no jantar (18h–21h)”, “Chamar o parceiro X e pausar destaque”, “Revisar raio em {cidade}”. This is the voice PRODUCT.md asked for.
3. **Dual-mode honesty in the data path.** Local rules still close with an action; suggested prompts include “Quais alertas e ações agora?”. `st.success` when the slice is clean is the right reassurance.

## Priority Issues

### [P1] The layout inverts the job: KPI wall first, differentiator last
- **What:** Six equal-weight `st.metric` tiles (`Pedidos`, `GMV`, `Ticket médio`, `Tempo de entrega`, `Nota média`, `Cancelamento`) open the main column. `Alertas do recorte` sit after a divider as default `st.error` / `st.warning` stacks. `Agente de insights` is the footer, under three Plotly tabs whose ranking tab is GMV.
- **Why it matters:** The operator’s question is “SLA / nota / cancelamento off — what do I do today?” The recruiter’s question is “is this more than a chart gallery?” Both are answered below the fold. GMV ranking is exactly the neighboring-product pattern this app claims not to be.
- **Fix:** After the recorte caption, surface high/warn alerts (or the success-all-clear) as the primary band. Encode the three operational KPIs (tempo, nota, cancelamento) as the hero row with teto state; demote GMV/ticket/pedidos. Put the agent adjacent to alerts or as a persistent rail, not after Operação. Ranking tab should default to risk (pior nota / SLA), not Top GMV — or GMV should be visually quieter than the action.
- **Suggested command:** `/impeccable layout`

### [P1] Chat history does not belong to the recorte on screen
- **What:** `st.session_state.messages` survives filter changes. The hint line updates (`filter_desc` · agente em {mode}), but the thread still shows answers from the previous slice. New replies use the new DataFrame; old ones do not announce they are stale. “Nova conversa” only appears when history exists and does not fire on recorte change.
- **Why it matters:** The whole product is “never answer the unfiltered set when filters are on.” A leftover answer about São Paulo while the sidebar says Recife is a silent lie — worse than a missing agent.
- **Fix:** Bind chat to a recorte fingerprint (period + cities + cuisines + restaurants + customer types + status). On mismatch: auto-clear, or stamp each turn with the recorte it used and show a blocking banner “Recorte mudou — respostas acima são de outro filtro” with one action to start Nova conversa. Never leave mixed context.
- **Suggested command:** `/impeccable harden`

### [P1] Recorte is easy to tighten, hard to leave
- **What:** Six sidebar controls (período + 5 multiselects). Empty multiselect = all, documented only in `filters.py`’s module docstring and a short caption. No “Limpar recorte” / “Todas as praças”. `date_input` with a tuple default can return a single date and silently shrink to one day. Restaurant options shrink with city/cuisine (good) but prior restaurant selections can yield an empty page without a one-click undo.
- **Why it matters:** Empty recorte is handled, but recovery is “manually unwind five widgets.” Power users will not save a view; first-timers will not know empty means all. Control/freedom is the emergency exit — it is missing.
- **Fix:** One `Limpar recorte` control that restores full period and empty multiselects. Show chips of active dimensions with remove. If period is a single date, label it as such. Keep empty = all, but state it on every widget (“vazio = todas”).
- **Suggested command:** `/impeccable onboard`

### [P2] Operational KPIs do not show the tetos they are judged by
- **What:** Tiles are beige cards with a 3px `#C2410C` left bar on *every* metric. 47 min looks like 4,35 looks like 6,2% looks like GMV. Thresholds live only in `agent/insights.py` (`DELIVERY_WARN/HIGH` 42/48, `RATING_WARN/LOW` 4.20/4.00, `CANCEL_WARN/HIGH` 7%/10%).
- **Why it matters:** Recognition vs recall. If the operator must scroll to alerts to know whether tempo is off, the KPI row is decoration. Color-only severity in Streamlit banners also fails Sam.
- **Fix:** Tempo / nota / cancelamento carry state (ok / atenção / crítico) in label + icon + text, not color alone. Print the teto on the tile (“teto 48 min”). Leave GMV/ticket without fake alarms.
- **Suggested command:** `/impeccable colorize`

### [P2] Copy and chrome disagree with the running product
- **What:** Agent caption: “com Groq ou OpenAI nos secrets”; runtime is OpenRouter (`llm_label`, `OPENROUTER_API_KEY`). Cancel *high* banner: “teto interno 7%” while `CANCEL_HIGH` is 10% (7% is warn). Rating *low* banner cites “meta interna 4,20” (the warn line). Ranking chart title “Top 12 restaurantes por GMV”. LLM exceptions swallow and fall back while the hint still says OpenRouter.
- **Why it matters:** Recruiter reads the caption as the stack. Operator reads 7% vs 10% as the rule. Inconsistent tetos train people to ignore alerts.
- **Fix:** One glossary for tetos; high-path copy uses the high threshold. Caption matches `llm_label()`. On LLM fail, say “regras locais (falha na API)”. Rename or demote the GMV ranking title so it is not the thesis.
- **Suggested command:** `/impeccable clarify`
